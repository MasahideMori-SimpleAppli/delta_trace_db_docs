Aggregate¶

Calculate count, sum, min, max and mean for the items that match a condition.

Overview¶

The aggregate operation calculates several aggregations at once and returns them as a single map (dict) in result.

  • This operation does not modify any data, and can be used inside a transaction.

  • The target items can be narrowed with an optional queryNode / query_node. If it is omitted, all items in the collection are targeted.

  • Each aggregation is defined with an Aggregation object.

  • The results are identical in Dart and Python, including floating-point sums.

  • Available from version 0.2.0.

Aggregation¶

Argument

Description

type / type_

EnumAggregateType.count_, sum_, min_, max_ or mean_.

field

The target field. Nested fields can be specified with dot notation. Required except for count_.

vType / v_type

The calculation type: floatStrict_ (default), decimal_ or rational_. Other types make the query fail. Ignored by count_.

alias

The key of the result. If omitted, the type name and the field name are joined (e.g. "sum_price"), or "count_" for count_ without a field.

scale, rounding

Used only for mean_ with decimal_, and required for it. The number of digits after the decimal point and the EnumRoundingMode (halfEven, halfUp, down, floor, ceiling).

vType

Accepted values

Result

floatStrict_

Numbers, and plain number strings such as "1.5" or "1e3" ("inf", "NaN", "1_000" and whitespace are rejected).

A floating-point number. Values are added from left to right in the stored order, so Dart and Python return the same value.

decimal_

Strings and PortableDecimal objects. Numbers are not converted.

An exact decimal string, e.g. "43.80".

rational_

Strings (including fractions such as "1/3"), PortableDecimal and PortableRational objects. Numbers are not converted.

An exact rational string, e.g. "73/5".

See Exact decimal / rational comparison for why numbers are not converted by decimal_ and rational_, and Exact Numbers for how to store such values.

Usage¶

import 'package:delta_trace_db/delta_trace_db.dart';

void main() {
  final db = DeltaTraceDatabase();
  db.executeQuery(
    RawQueryBuilder.add(
      target: 'orders',
      rawAddData: [
        {'status': 'paid', 'price': '10.50', 'qty': 2},
        {'status': 'paid', 'price': '3.3', 'qty': 1.5},
        {'status': 'paid', 'price': '30', 'qty': 4},
        {'status': 'cancel', 'price': '100', 'qty': 10},
      ],
    ).build(),
  );

  final result = db.executeQuery(
    RawQueryBuilder.aggregate(
      target: 'orders',
      queryNode: FieldEquals('status', 'paid'),
      aggregations: [
        Aggregation(EnumAggregateType.count_, alias: 'n'),
        Aggregation(
          EnumAggregateType.sum_,
          field: 'price',
          vType: EnumValueType.decimal_,
          alias: 'total',
        ),
        Aggregation(
          EnumAggregateType.mean_,
          field: 'price',
          vType: EnumValueType.decimal_,
          scale: 2,
          rounding: EnumRoundingMode.halfEven,
          alias: 'avg',
        ),
        Aggregation(
          EnumAggregateType.max_,
          field: 'price',
          vType: EnumValueType.decimal_,
        ),
        Aggregation(EnumAggregateType.sum_, field: 'qty'),
      ],
    ).build(),
  );
  print(result.result.first);
  print("hitCount = ${result.hitCount}");
}

    ],
).build())

result = db.execute_query(RawQueryBuilder.aggregate(
    target="orders",
    query_node=FieldEquals("status", "paid"),
    aggregations=[
        Aggregation(EnumAggregateType.count_, alias="n"),
        Aggregation(EnumAggregateType.sum_, field="price",
                    v_type=EnumValueType.decimal_, alias="total"),
        Aggregation(EnumAggregateType.mean_, field="price",
                    v_type=EnumValueType.decimal_, scale=2,
                    rounding=EnumRoundingMode.halfEven, alias="avg"),
        Aggregation(EnumAggregateType.max_, field="price",
                    v_type=EnumValueType.decimal_),
        Aggregation(EnumAggregateType.sum_, field="qty"),
    ],
).build())
print(result.result[0])
print(f"hit_count = {result.hit_count}")

Result¶

This function returns a QueryResult.

Example output (Dart):

{n: 3, total: 43.80, avg: 14.60, max_price: 30, sum_qty: 7.5}
hitCount = 3

  • The aggregation results are stored as a single map (dict) in result.

  • hitCount / hit_count is the number of items that matched the condition.

  • Because this query only reads data, updateCount is always 0.

Security¶

Warning

Treat the aggregate permission as equivalent to read (search) access.

Although this query does not return the items themselves, their contents can still be discovered. For example, by repeating count_ with FieldStartsWith while extending the prefix one character at a time, the full value of a field can be found. In addition, min_ and max_ return field values directly.

Grant the aggregate permission only to users who are allowed to read the target collection.

Notes¶

  • Null and missing values are excluded from every aggregation.

  • count_ without a field counts the matched items. With a field, it counts the items whose value is not null. count_ never converts values, so it works for any type.

  • If there are no values, count_ is 0, sum_ is 0 (0.0 or "0"), and min_, max_ and mean_ are null.

  • If a value cannot be converted, or a definition is invalid (e.g. a duplicate key, or mean_ with decimal_ without scale), the query fails with isSuccess = false and the reason in errorMessage / error_message. A wrong result is never returned silently.

  • In Python, do not use the built-in sum() when the result must match the Dart version; since Python 3.12 it uses compensated summation and can return a different value.

  • On the server side, the aggregate permission is required. A search permission does not allow this query.

  • cause can be used for auditing or operational logging.
