Bases: CloneableFile

(en) A definition of a join in an aggregate query. For each item of the target collection, the item of collection whose foreign_key value equals the local_key value is attached under alias, so its fields can be referenced as “alias.field” in the query node, the group keys and the aggregations. Exactly one item must match. If no item matches, more than one item matches, or the local_key value is None, the query fails. Values are compared by their JSON representation, so 1 and “1” do not match.

(ja) aggregateクエリにおける結合の定義です。 対象コレクションの各アイテムに、foreign_key の値が local_key の値と等しい collection のアイテムを alias の名前で付けます。 これにより、検索ノード・グループキー・集計で “alias.フィールド” として参照できます。 一致するアイテムは必ず1件である必要があります。一致するアイテムがない場合、 複数ある場合、または local_key の値が None の場合はクエリが失敗します。 値は JSON での表現で比較されるため、1 と “1” は一致しません。

Parameters:

  • collection (str) – The name of the collection to join.

  • local_key (str) – The field of the target item whose value is used for the join. Nested fields and fields of earlier joins can be specified with dot notation.

  • foreign_key (str) – The field of the joined item that is compared with the local_key value. Nested fields can be specified with dot notation.

  • alias (str) – The name under which the joined item is attached. It must not be empty, contain a dot, or be the same as a field of the target item or another alias.
