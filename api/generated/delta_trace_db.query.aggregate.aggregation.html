Bases: CloneableFile

(en) A definition of one aggregation in an aggregate query.

(ja) aggregateクエリにおける、1つの集計の定義です。

Parameters:

  • type (EnumAggregateType) – The aggregation type.

  • field (Optional[str]) – The target field name. Nested fields can be specified with dot notation. This or fields is required except for count_. For count_, if specified, only items whose field value is not None are counted. None and missing values are always excluded from the calculation. Cannot be used together with fields.

  • v_type (EnumValueType) –

    The calculation type for sum_, min_, max_ and mean_. Only EnumValueType.floatStrict_, EnumValueType.decimal_ and EnumValueType.rational_ are supported. Ignored by count_.

    • floatStrict_: Calculated with float. Numbers and plain number strings are converted. The result is a float.

    • decimal_: Calculated exactly. Only str and PortableDecimal are converted. The result is a str.

    • rational_: Calculated exactly. Only str, PortableDecimal and PortableRational are converted. The result is a str.

    If a value cannot be converted, the query fails.

  • alias (Optional[str]) – The key of this result in the result dict. If None, “{type name}{field}” is used (e.g. “sum_price”), “{type name}{fields joined with *}” for fields (e.g. “sum_quantity*price”), or “count_” for count_ without a field.

  • scale (Optional[int]) – Used only for mean_ with decimal_, and required for it. The number of digits after the decimal point of the result.

  • rounding (Optional[EnumRoundingMode]) – Used only for mean_ with decimal_, and required for it. The rounding mode of the result.

  • fields (Optional[List[str]]) – Used instead of field to aggregate the product of the values of these fields (e.g. [“quantity”, “p.price”] for sales). The values of each item are converted with v_type and multiplied in order. If any of the values is None or missing, the item is excluded. For count_, the number of items whose values are all not None. Must not be empty.
