(en) Utilities for EnumValueType.decimal_ and EnumValueType.rational_. Only str and the simple_portable_numeric types are converted. Numbers such as int and float are rejected, because their exactness cannot be guaranteed (e.g. int is a double on the web in Dart, and the string form of float differs between Dart and Python).

(ja) EnumValueType.decimal_ と EnumValueType.rational_ 用のユーティリティです。 変換対象は str と simple_portable_numeric の型のみです。 int や float などの数値型は、正確さを保証できないため変換しません （例：Dartの Web では int も double であり、float の文字列表現は Dart と Python で異なります）。
