Bases: CloneableFile

(en) A definition of a key used to group items in an aggregate query. Items with the same value (or the same period if unit is set) are aggregated together, and each group becomes one result dict that contains the key value under output_key.

(ja) aggregateクエリでアイテムをグループ化するキーの定義です。 同じ値（unit を指定した場合は同じ期間）のアイテムがまとめて集計され、 各グループは、キーの値を output_key に持つ1つの結果の辞書になります。

Parameters:

  • field (str) – The field whose value is used as the key. Nested fields and fields of joined items can be specified with dot notation. Items whose value is None or missing form a group whose key is None. Values are compared by their JSON representation, so 1 and “1” are different keys.

  • unit (Optional[EnumAggregateGroupUnit]) – If set, the value is read as an ISO 8601 date-time string (the same format as EnumValueType.datetime_) and the key is the label of the period that contains it. If the value cannot be read, the query fails.

  • utc_offset_minutes (Optional[int]) – Used only with unit. The offset from UTC in minutes of the time zone in which the periods are divided (e.g. 540 for UTC+09:00). Values without a time zone are read as times in this time zone. Must be greater than -1440 and less than 1440. If None, 0 (UTC) is used.

  • week_start (Optional[int]) – Used only with EnumAggregateGroupUnit.week. The first day of the week as an ISO 8601 weekday number (1 = Monday, …, 7 = Sunday). If None, 1 (Monday) is used.

  • start_month (Optional[int]) – Used only with EnumAggregateGroupUnit.quarter and EnumAggregateGroupUnit.year. The month in which the year starts (1-12), e.g. 4 for a fiscal year that starts in April. If None, 1 is used.

  • alias (Optional[str]) – The key of this value in the result dict. If None, field is used.
