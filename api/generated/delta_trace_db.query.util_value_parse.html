class delta_trace_db.query.util_value_parse.UtilValueParse¶

Bases: object

(en) Conversions used by EnumValueType that give the same results as the Dart version (int.parse, double.parse and DateTime comparison on the Dart VM). Python’s int() and float() accept more forms (e.g. “1_000”, “inf” and non-ASCII digits), so they are not used directly.

(ja) EnumValueType で使用する、Dart版（Dart VM の int.parse、double.parse、DateTime の比較）と 同じ結果になる変換です。 Python の int() や float() はより多くの形式（”1_000”、”inf”、ASCII以外の数字など）を受け付けるため、 直接は使用しません。

static datetimes(f_value: Any, value: Any, naive_utc_offset_minutes: int | None) → Tuple[datetime, datetime]¶

(en) Returns the field value and the compare value for datetime_ comparison. If naive_utc_offset_minutes is not None, naive values are converted with that offset. Otherwise, ValueError is raised if exactly one of them is timezone-aware, so that mixing naive and aware datetimes is treated as a conversion failure, the same as the Dart version.

(ja) datetime_ の比較のために、フィールドの値と比較値を返します。 naive_utc_offset_minutes が None でない場合、naive な値はそのオフセットで変換されます。 それ以外の場合、一方だけがタイムゾーン付きなら ValueError を送出し、 Dart版と同様に naive と aware の混在を変換失敗として扱います。

Raises:

ValueError – If the value cannot be parsed or the timezone awareness differs.

static parse_int(text: str) → int¶

(en) Parses a string like Dart’s int.parse: surrounding whitespace is ignored, decimal digits or a 0x hexadecimal number with an optional sign are accepted, and the result is a 64-bit integer (hexadecimal values wrap around).

(ja) Dart の int.parse と同様に文字列を解析します。前後の空白は無視し、 符号付きの10進数または 0x で始まる16進数を受け付け、結果は64ビット整数です （16進数は折り返します）。

Parameters:

text (str) – The string to parse.

Raises:

ValueError – If the string cannot be parsed.

static parse_iso_datetime(text: str) → datetime¶

(en) Parses an ISO 8601 string for datetime_, accepting exactly the same strings as the Dart version. Out-of-range components (e.g. month 13, February 30, hour 24) and formats the Dart version does not accept (e.g. week dates) are rejected.

(ja) datetime_ 用に ISO 8601 の文字列を解析します。Dart版と全く同じ文字列を受け付けます。 範囲外の値（13月、2月30日、24時など）や、Dart版が受け付けない形式（週番号形式など）は拒否します。

Parameters:

text (str) – The string to parse.

Raises:

ValueError – If the string cannot be parsed.
