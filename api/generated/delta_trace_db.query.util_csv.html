(en) Reads CSV text into items for DeltaTraceDB. This is used by the addCsv and clearAddCsv queries.

(ja) CSV のテキストを DeltaTraceDB の要素に変換します。 addCsv 及び clearAddCsv クエリで使用されます。

static to_items(text: str) → List[Dict[str, Any]]¶

(en) Converts CSV text to a list of dicts. The first record is the header, and each following record becomes a dict of {column name: cell text}. All values are kept as strings. Values are separated by commas, may be enclosed in double quotes (‘””’ inside quotes is a quote, and quoted values may contain line breaks), and lines end with LF, CRLF or CR. A leading BOM and trailing empty lines are ignored.

(ja) CSV のテキストを dict のリストに変換します。 最初のレコードをヘッダーとし、以降の各レコードを {列名: セルの文字列} の dict にします。値は全て文字列のままです。 値はカンマ区切りで、ダブルクォートで囲めます（囲んだ中の ‘””’ は引用符1つで、 改行も含められます）。行末は LF、CRLF、CR のいずれかです。 先頭の BOM と末尾の空行は無視します。

Parameters:

text (str) – The CSV text.

Raises:

CsvFormatError – If the CSV is invalid.
