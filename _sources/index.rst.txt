DeltaTraceDB Documentation
==========================

Welcome to the official documentation for **DeltaTraceDB**.

DeltaTraceDB currently provides libraries for multiple languages, with examples for each operation.

Supported Versions
------------------

- **Dart**: `[https://pub.dev/packages/delta_trace_db] <https://pub.dev/packages/delta_trace_db>`__
  A Dart library for integrating DeltaTraceDB into your Flutter or Dart applications.

- **Python**: `[https://pypi.org/project/delta-trace-db/] <https://pypi.org/project/delta-trace-db/>`__
  A Python library for managing and interacting with DeltaTraceDB databases.

Maintenance Tool
----------------

If you need to manually adjust the database contents for maintenance or inspection purposes, a dedicated open-source app is available:

- **DeltaTraceStudio**: `[https://github.com/MasahideMori-SimpleAppli/delta_trace_studio] <https://github.com/MasahideMori-SimpleAppli/delta_trace_studio>`__
