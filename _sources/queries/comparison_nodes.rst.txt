.. _comparison_nodes:

======================================
Comparison Nodes
======================================

**Comparison nodes** are used to compare field values in query conditions.

Overview
----------------------------
Each comparison node inherits from :code:`QueryNode` and evaluates whether a field
in the item meets a specific condition.

Supported Comparison Nodes
----------------------------
Below is a list of all available comparison nodes and their behaviors.

**Equality**
   - **FieldEquals(field, value, vType=auto_)**
     True if the field equals the value.

   - **FieldNotEquals(field, value, vType=auto_)**
     True if the field does not equal the value.

**Relational (Greater/Less)**
   - **FieldGreaterThan(field, value, vType=auto_)**
     True if the field value is greater than the given value.

   - **FieldGreaterThanOrEqual(field, value, vType=auto_)**
     True if the field value is greater than or equal to the given value.

   - **FieldLessThan(field, value, vType=auto_)**
     True if the field value is smaller than the given value.

   - **FieldLessThanOrEqual(field, value, vType=auto_)**
     True if the field value is smaller than or equal to the given value.

**Membership**
   - **FieldContains(field, value)**
     True if the field (which must be a string or list) contains the given value.

   - **FieldIn(field, list)**
     True if the field’s value is included in the given list.

   - **FieldNotIn(field, list)**
     True if the field’s value is *not* included in the given list.

**Pattern Matching**
   - **FieldMatchesRegex(field, pattern)**
     True if the field’s value matches the regular expression.

   - **FieldStartsWith(field, prefix)**
     True if the field’s value starts with the specified prefix.

   - **FieldEndsWith(field, suffix)**
     True if the field’s value ends with the specified suffix.


vType (EnumValueType)
----------------------------

The equality and relational comparison nodes accept an optional ``vType`` parameter of type ``EnumValueType``.
This controls how both the field value and the comparison value are cast before the comparison is performed.
If a cast fails (e.g. the value cannot be converted to the specified type), the result is always ``False``.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Value
     - Behavior
   * - ``auto_`` *(default)*
     - Compares values as-is without any conversion.
   * - ``datetime_``
     - Parses both values as ISO 8601 strings and compares them as DateTime objects.
       If a ``DateTime`` object is passed directly as the value, this type is set automatically.
   * - ``int_``
     - Converts both values to integers before comparing.
   * - ``floatStrict_``
     - Converts both values to floating-point numbers and compares them exactly.
   * - ``floatEpsilon12_``
     - Converts both values to floating-point numbers and treats them as equal
       if the absolute difference is less than ``1e-12``.
   * - ``boolean_``
     - Converts both values to strings, lowercases them, and compares as booleans.
   * - ``string_``
     - Converts both values to strings and compares them.
   * - ``stringIgnoreCase_``
     - Converts both values to strings, lowercases them, and compares them
       (case-insensitive string comparison).
   * - ``decimal_``
     - Converts both values to ``PortableDecimal`` and compares them exactly by value
       (see :ref:`exact_decimal_rational`).
       If a ``PortableDecimal`` object is passed directly as the value, this type is set automatically.
   * - ``rational_``
     - Converts both values to ``PortableRational`` and compares them exactly by value
       (see :ref:`exact_decimal_rational`).
       If a ``PortableRational`` object is passed directly as the value, this type is set automatically.

.. tab-set::

   .. tab-item:: Dart

      .. code-block:: dart

         import 'package:delta_trace_db/delta_trace_db.dart';

         // Case-insensitive string comparison
         final node = FieldEquals('status', 'active',
             vType: EnumValueType.stringIgnoreCase_);
         node.evaluate({'status': 'Active'});  // true
         node.evaluate({'status': 'ACTIVE'});  // true

         // Integer comparison (field stored as string)
         final node2 = FieldGreaterThan('count', '10',
             vType: EnumValueType.int_);
         node2.evaluate({'count': '20'});  // true

   .. tab-item:: Python

      .. code-block:: python

         from delta_trace_db import FieldEquals, FieldGreaterThan, EnumValueType

         # Case-insensitive string comparison
         node = FieldEquals('status', 'active',
             v_type=EnumValueType.stringIgnoreCase_)
         node.evaluate({'status': 'Active'})  # True
         node.evaluate({'status': 'ACTIVE'})  # True

         # Integer comparison (field stored as string)
         node2 = FieldGreaterThan('count', '10',
             v_type=EnumValueType.int_)
         node2.evaluate({'count': '20'})  # True

.. _exact_decimal_rational:

Exact decimal / rational comparison
------------------------------------

``decimal_`` and ``rational_`` use the
`simple_portable_numeric <https://pub.dev/packages/simple_portable_numeric>`__ package,
which gives identical results in Dart and Python.
Unlike ``floatStrict_``, no digits are lost, so this is suitable for values such as prices.

- Values are compared by numeric value, so ``"1.50"`` equals ``"1.5"``.
- ``decimal_`` accepts plain decimal strings such as ``"-12.340"``.
  ``rational_`` also accepts fractions such as ``"1/3"``.
  Exponent notation (``"1e3"``), whitespace and non-ASCII digits are rejected.
- **Only strings and** ``PortableDecimal`` / ``PortableRational`` **objects are converted.**
  Numbers such as int and double (float) are treated as conversion failures, because their exactness
  cannot be guaranteed (e.g. int is a double on the web in Dart, and the string form of double differs
  between Dart and Python). This also applies to the comparison value,
  so pass ``"11"`` instead of ``11``. Store such values in the DB as strings.
- ``PortableDecimal``, ``PortableRational`` and ``EnumRoundingMode`` are re-exported from ``delta_trace_db``.
- Queries using these types cannot be read by delta_trace_db versions earlier than 0.2.0.
- For how to store such values in data classes, see :doc:`../best_practices/exact_numbers`.

.. tab-set::

   .. tab-item:: Dart

      .. code-block:: dart

         import 'package:delta_trace_db/delta_trace_db.dart';

         final node = FieldEquals('price', '1.5', vType: EnumValueType.decimal_);
         node.evaluate({'price': '1.50'}); // true
         node.evaluate({'price': 1.5}); // false (numbers are not converted)

         // vType is set automatically, and the value is saved as a String.
         final node2 = FieldGreaterThan('price', PortableDecimal.parse('0.1'));
         node2.evaluate({'price': '0.10000000000000000001'}); // true

         final node3 = FieldLessThan('ratio', '1/3', vType: EnumValueType.rational_);
         node3.evaluate({'ratio': '0.333'}); // true

   .. tab-item:: Python

      .. code-block:: python

         from delta_trace_db import (EnumValueType, FieldEquals, FieldGreaterThan,
                                     FieldLessThan, PortableDecimal)

         node = FieldEquals('price', '1.5', v_type=EnumValueType.decimal_)
         node.evaluate({'price': '1.50'})  # True
         node.evaluate({'price': 1.5})  # False (numbers are not converted)

         # v_type is set automatically, and the value is saved as a str.
         node2 = FieldGreaterThan('price', PortableDecimal.parse('0.1'))
         node2.evaluate({'price': '0.10000000000000000001'})  # True

         node3 = FieldLessThan('ratio', '1/3', v_type=EnumValueType.rational_)
         node3.evaluate({'ratio': '0.333'})  # True

Examples
----------------------------

.. tab-set::

   .. tab-item:: Dart

      .. code-block:: dart

         import 'package:delta_trace_db/delta_trace_db.dart';

         final node = FieldGreaterThanOrEqual('score', 80);
         final result = node.evaluate({'score': 85}); // true

         final node2 = FieldLessThanOrEqual('age', 30);
         final result2 = node2.evaluate({'age': 25}); // true

   .. tab-item:: Python

      .. code-block:: python

         from delta_trace_db import FieldGreaterThanOrEqual, FieldLessThanOrEqual

         node = FieldGreaterThanOrEqual('score', 80)
         result = node.evaluate({'score': 85})  # True

         node2 = FieldLessThanOrEqual('age', 30)
         result2 = node2.evaluate({'age': 25})  # True
